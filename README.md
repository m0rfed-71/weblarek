# Интернет-магазин «Web-Larёk»
«Web-Larёk» — это интернет-магазин с товарами для веб-разработчиков, где пользователи могут просматривать товары, добавлять их в корзину и оформлять заказы. Сайт предоставляет удобный интерфейс с модальными окнами для просмотра деталей товаров, управления корзиной и выбора способа оплаты, обеспечивая полный цикл покупки с отправкой заказов на сервер.

## Архитектура приложения

Код приложения разделен на слои согласно парадигме MVP (Model-View-Presenter), которая обеспечивает четкое разделение ответственности между классами слоев Model и View. Каждый слой несет свой смысл и ответственность:

Model - слой данных, отвечает за хранение и изменение данных.  
View - слой представления, отвечает за отображение данных на странице.  
Presenter - презентер содержит основную логику приложения и  отвечает за связь представления и данных.

Взаимодействие между классами обеспечивается использованием событийно-ориентированного подхода. Модели и Представления генерируют события при изменении данных или взаимодействии пользователя с приложением, а Презентер обрабатывает эти события используя методы как Моделей, так и Представлений.

### Базовый код

#### Класс Component
Является базовым классом для всех компонентов интерфейса.
Класс является дженериком и принимает в переменной `T` тип данных, которые могут быть переданы в метод `render` для отображения.

Конструктор:  
`constructor(container: HTMLElement)` - принимает ссылку на DOM элемент за отображение, которого он отвечает.

Поля класса:  
`container: HTMLElement` - поле для хранения корневого DOM элемента компонента.

Методы класса:  
`render(data?: Partial<T>): HTMLElement` - Главный метод класса. Он принимает данные, которые необходимо отобразить в интерфейсе, записывает эти данные в поля класса и возвращает ссылку на DOM-элемент. Предполагается, что в классах, которые будут наследоваться от `Component` будут реализованы сеттеры для полей с данными, которые будут вызываться в момент вызова `render` и записывать данные в необходимые DOM элементы.  
`setImage(element: HTMLImageElement, src: string, alt?: string): void` - утилитарный метод для модификации DOM-элементов `<img>`


#### Класс Api
Содержит в себе базовую логику отправки запросов.

Конструктор:  
`constructor(baseUrl: string, options: RequestInit = {})` - В конструктор передается базовый адрес сервера и опциональный объект с заголовками запросов.

Поля класса:  
`baseUrl: string` - базовый адрес сервера  
`options: RequestInit` - объект с заголовками, которые будут использованы для запросов.

Методы:  
`get(uri: string): Promise<object>` - выполняет GET запрос на переданный в параметрах ендпоинт и возвращает промис с объектом, которым ответил сервер  
`post(uri: string, data: object, method: ApiPostMethods = 'POST'): Promise<object>` - принимает объект с данными, которые будут переданы в JSON в теле запроса, и отправляет эти данные на ендпоинт переданный как параметр при вызове метода. По умолчанию выполняется `POST` запрос, но метод запроса может быть переопределен заданием третьего параметра при вызове.  
`handleResponse(response: Response): Promise<object>` - защищенный метод проверяющий ответ сервера на корректность и возвращающий объект с данными полученный от сервера или отклоненный промис, в случае некорректных данных.

#### Класс EventEmitter
Брокер событий реализует паттерн "Наблюдатель", позволяющий отправлять события и подписываться на события, происходящие в системе. Класс используется для связи слоя данных и представления.

Конструктор класса не принимает параметров.

Поля класса:  
`_events: Map<string | RegExp, Set<Function>>)` -  хранит коллекцию подписок на события. Ключи коллекции - названия событий или регулярное выражение, значения - коллекция функций обработчиков, которые будут вызваны при срабатывании события.

Методы класса:  
`on<T extends object>(event: EventName, callback: (data: T) => void): void` - подписка на событие, принимает название события и функцию обработчик.  
`emit<T extends object>(event: string, data?: T): void` - инициализация события. При вызове события в метод передается название события и объект с данными, который будет использован как аргумент для вызова обработчика.  
`trigger<T extends object>(event: string, context?: Partial<T>): (data: T) => void` - возвращает функцию, при вызове которой инициализируется требуемое в параметрах событие с передачей в него данных из второго параметра.

### Данные 
Интернет магазин получает два типа данных: данные о товаре и данные о покупателе. 

#### Данные о товаре 
Релизованы с помощью интерфейса `interface IProduct` - хранит в себе:
`id` -уникальный номер товара;
`description` - описание товара;
`image`- изображение товара;
`title`- название товара;
`category` - категория товара;
`price` - цена товара;

#### Данные о покупателе
Реализованы с помощью интерфейса `interface IBuyer` - хранит в себе:
`payment` - способ оплаты товара;
`email` - электронную почту покупателя;
`phone` - телефон покупателя;
`address` - адрес покупателя;

### Модели данных

#### Класс catalog 
 Содержит в себе данные о хранении товаров, которые можно купить в приложении 

 Поля класса: 
 `items: IProduct[] = []` -хранит массив всех товаров
 `preview: IProduct | null = null` - тип: массив IProduct или "значение отстутствует". Хранит массив IProduct и отвечает за выбранный пользователем товар для подробного отображения. 
 
 Методы класса: 
 `setItems(items: IProduct[]): void` - в параметрах содержит массив товаров и сохраняет его
 `getItems(): IProduct[]` - получение массива товаров из модели
 `getItem(id: string): IProduct | undefined` - получение конкретного товара по его id (с типом строка)
 `setPreview(item: IProduct): void` - сохранение конкретного товара для подробного отображения
 ` getPreview(): IProduct | null` - получение конкретного товара для подробного отображения

#### Класс basket 
Отвечает за хранение товаров, которые пользователь выбрал для покупки

Поля класса:
`items: IProduct[] = []` -хранит массив всех товаров

Методы класса: 
` getItems(): IProduct[]` - получение массива товаров, которые добавлены в корзину и возвращение их с типом строка
`addItem(item: IProduct): void` - добавление товара в корзину, который был получен в качестве параметра из массива IProduct
`removeItem(item: IProduct): void` - удаление товара из корзины
`clear(): void` - очистка корзины
`getTotal(): number` - получение суммы стоимости всех товаров в корзине
` getCount(): number` - получение количества товаров в корзине
`hasItem(id: string): boolean` - проверка наличия товара в корзине по его id

#### Класс buyer
Содержит в себе данные покупателя, который тот должен указать при оформлении заказа

Поля класса: 
`payment: TPayment | ''` - вид оплаты card или cash
`email = ''` - email с типом `string`
`phone = ''` - телефон с типом `string`
`address = ''` - адрес с типом `string`

Методы класса:
`setData(data: Partial<IBuyer>): void` - сохраняет данные о полях класса, при этом есть возможность сохранить только одно поле
`getData()` - получение всех данных о покупателе
`clear(): void` - очистка данных о покупателе
`validate(): Partial<Record<keyof IBuyer, string>>` - проверка на заполнение всех данных о покупателе

### Слой коммуникации 
Делает запрос на серввер для получения с сервера массива товаров, чтобы подтвердить покупку

#### Класс communication
Делает запрос на сервер для получения массива товаров, а с сервера получает запрос подтверждающий покупку товара

Поля класса: 
`api: Api` - делает запрос на сервер

Методы класса: 
`get(): Promise<IProductsResponse>` - метод get делает запрос на сервер и в ответ возвращает массив товаров
`post(order: IOrder): Promise<IOrderResult>` - делает post запрос на сервер и ответ возвращает объект, подтверждающий покупку

### Классы представления

#### Класс Basket
Отображает модальное окно корзины с количеством товаров, их ценой и кнопкой оформить заказ

Поля класса: 
`listElement: HTMLElement` - список товаров в корзине
`priceElement: HTMLElement` - цена товара
`orderButton: HTMLButtonElement` - кнопка оформить заказ

Методы класа:
`set items` - добавляет товары в список корзины, а также делает кнопку "оформить" неактивной, если в списке нет товаров для заказа
`set total` - формирует общую сумму стоимости товаров в корзине

#### Класс BasketItem 
Отображает товары в модальном окне корзины

Поля класса:
`indexElement: HTMLElementю` - отображает индекс товара в списке покупок
`titleElement: HTMLElement` - отображает название товара 
`priceElement: HTMLElement` - отображает цену товара
`deleteButton: HTMLButtonElement` - отображает кнопку удаления товара из корзины

Методы класса:
`set index(value: number)`- устанавливает индекс товара в корзине
`set title(value: string)` - устанавливает название товара в корзине
`set price(value: number | null)` - устанавливает цену товара в корзине

#### Класс Card 
Отображает краткую информацию о карточке товара

Поля класса: 
`titleElement: HTMLElement` - отображает название товара
`imageElement: HTMLImageElement` - отображает картинку товара
`categoryElement: HTMLElement` - отображает категорию товара
`priceElement: HTMLElement` - отображает цену товара 

Методы класса: 
`set title(value: string)` - устанавливает название товара на карточке
`set image(value: string)` - устанавливает картинку товара на карточке
`set category(value: CategoryKey)` - устанавливает категорию товара на карточке
`set price(value: number | null)` - устанавливает цену товара на карточке 

#### Класс CardCatalog 
Отображает все карточки товаров на главной странице

Поля класса: 
`items: HTMLElement[]` - сама карточка

Методы классы: 
`set items(items: HTMLElement[])` - добавляет все карточки товаров на главную страницу

#### Класс Contacts 
Отображает форму с контактами заказчика для оформления заказа товара

Поля класса: 
`emailInput: HTMLInputElement` - поле для указания email 
`phoneInput: HTMLInputElement` - поле для указания номера телефона 

Методы класса: 
`set email(value: string)` - сохраняет введенный email
`set phone(value: string)` - сохраняет введенный номер телефона

#### Класс Form
Отвечает за формы оформления заказа 

Поля класса: 
`submitButton: HTMLButtonElement` - отвечает за отображение кнопки "Далее"
`errorsElement: HTMLElement` - выводит ошибки, если какой-то input формы не заполнен
`formName: string` - отвечает за название формы

Методы класса: 
`set valid(value: boolean)` - проверяет валидность формы, и если форма не валидна, кнопка далее недоступна
`set errors(value: string)` - показывает ошибки при заполнении формы, если какие-то поля не заполнены

#### Класс Header 
Отображает шапку сайта и счетчик товаров в корзине

Поля класса: 
`counterElement: HTMLElement` - отображает счетчик товаров в корзине
`basketButton: HTMLButtonElement` - отображает кнопку корзины

Методы класса: 
`set counter(value: number)` - устанавливает счетчик товаров в корзине

#### Класс Modal 
Отвечает за всплытие модального окна и отображение контента в нем

Поля класса:
`closeButton: HTMLButtonElement` - кнопка отвечающая за закртие модального окна 
`contentElement: HTMLElement` - элемент отвечающий за отобра 

Метода класса: 
`set content(value: HTMLElement)` - устанавливает контент внутри модального окна
`open(): void` - отвечает за открытие модального окна 
`close(): void` - отвечает за закрытие модального окна 

#### Класс Order
Отображает форму первого этапа оформления заказа 

Поля класса:
`paymentButtons: HTMLButtonElement[]` - кнопки выбора способа оплаты
`addressInput: HTMLInputElement` - input введения адреса

Методы класса: 
`set payment(value: TPayment | '')` - устанавливает способ оплаты
`set address(value: string)` -  установка input для введения адреса доставки

#### Класс ProductPreview 
Отображает подробную информацию о товаре

Поля класса: 
`textElement: HTMLElement` - отображает описание товара
`buttonElement: HTMLButtonElement` - кнопка добавления товара в корзину

Методы класса: 
`set description(value: string)` - устанавливает описание для товара
`set button(value: string)` - устанавливает кнопку добавления товара в корзину

`descriptionElement: HTMLElement` - текст в модальном окне
`closeButton: HTMLButtonElement` - кнопка закрытия модального окна "За новыми покупками!"

Методы класса:
